# 🐴 Hermes Hub Gateway (HHG)

Desktop Unified MCP Hub, Isolated Multi-Workspace Manager, and Continuous Transcript Watcher for SIMGOSv2 AI Agents.

## Changelog v0.2.1
- **Explicit Non-Blank Tray Icon:** Ikon tray Windows diikat langsung ke biner aplikasi agar tidak lagi muncul kotak blank/transparan di taskbar.
- **MCP Servers Hub Edit & Delete:** Kemampuan mengedit parameter command, argumen, dan deskripsi MCP, serta menghapus MCP server.
- **Global Telegram Broadcast Bot:** Pengaturan bot notifikasi telegram terpusat di tab Settings, diteruskan otomatis via payload handshake ke Hermes Evaluator pada fresh-install.
- **Skills Hierarchy & Reader:** Visualisasi hirarki SOP (SKILL.md) dan sub-berkas referensi (references/) lengkap dengan atribusi pembuat SOP.
- **Single-Instance IPC:** Membuka shortcut desktop otomatis me-restore jendela aktif tanpa freeze/End Task.
